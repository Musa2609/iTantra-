01 / Problem & Solution

Normal voice assumes bandwidth.

Traditional voice codecs (Opus, AAC) drop completely when link bandwidth collapses below 8 kbps. iTantra quantizes speech into neural vector codebooks to maintain voice communication over extreme constraints.

Standard Voice Codecs (Opus / AAC) DROPS < 8 kbps

Standard codecs transmit continuous spectral frames requiring 32 kbps to 64 kbps. On satellite blackouts, emergency mesh links, or HF radio fading, packets drop and audio turns into unrecoverable noise.

Required Bandwidth:32.0 - 64.0 kbps
Payload Architecture:Uncompressed PCM / Frames
Low-Bandwidth Behavior:Total Signal Loss
iTantra Neural Speech System OPERATIONAL @ 6.0 kbps

iTantra compresses 24kHz speech into discrete Vector Quantization (VQ) codebook indices. Payloads are chunked into 256-byte packets verified with CRC32 checksums for resilient software or acoustic transmission.

Target Speech Bitrate:6.0 kbps
Payload Architecture:VQ Codebooks + CRC32
Low-Bandwidth Behavior:Intelligible 24kHz Speech

06 / Technical Knowledge Base

Frequently Asked Questions

iTantra is a low-bandwidth multilingual voice communication system. It compresses voice audio using Meta EnCodec neural speech tokens and transmits 256-byte packet streams over bandwidth-constrained links.
EnCodec uses Vector Quantization (VQ) neural codebooks to compress 24kHz voice audio down to 6.0 kbps (and lower), achieving over 18x to 235x data reduction while preserving speech intelligibility.
ggwave is a lightweight acoustic data-over-sound protocol that encodes binary packets into sound tones for transmission across audio links or software loopback.
Packetization breaks continuous VQ byte streams into 256-byte sequence-numbered frames so that individual lost or corrupted packets can be isolated independently.
CRC32 (Cyclic Redundancy Check) computes a 32-bit checksum for each packet payload before transmission, enabling 100% data corruption verification at the receiver.
iTantra's primary function is neural voice-to-voice communication. However, it integrates AI4Bharat IndicConformer-600M for optional speech-to-text transcription.
Support includes Hindi, Gujarati, Marathi, Kannada, Malayalam, Tamil, Telugu, Odia, Bengali, and English.
By transmitting compact VQ neural codebook indices rather than uncompressed PCM audio, payload size is reduced significantly, allowing voice communication over constrained links.
The receiver depacketizes and verifies CRC32 checksums, reassembles VQ code tensors, and passes them to the EnCodec neural decoder to synthesize 24kHz voice output.
Software loopback is verified PASS. Physical acoustic transmission requires compatible speaker and microphone acoustic hardware conditions.
