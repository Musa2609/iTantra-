Continuous Signal Transmission System

Scroll to follow the central signal path as speech transforms from raw PCM audio through neural vector codebooks, sequence packetization, and CRC32 verification back to 24kHz output speech.

1
STAGE 01 // INPUT 24,000 Hz PCM

Voice Audio Input Waveform

Raw microphone capture generating uncompressed PCM audio signal.

2
STAGE 02 // NEURAL QUANTIZATION 6.0 kbps Target

Meta EnCodec Encoder (Waveform Compresses)

Residual Vector Quantization (RVQ) squashes speech amplitude into discrete latent codebook stages.

3
STAGE 03 // REPRESENTATION (1, 8, N) Tensor

Discrete Codebook Points

Continuous audio becomes discrete integer indices referencing 1,024 vector codebook entries.

[384][102][941][045][612][820][119]
4
STAGE 04 // SERIALIZATION Binary Stream

Binary Byte Representation

Encodes integer codebook indices and scale factors into compact binary payload bytes.

01001001 01010100 01000001 01001110 00000001
5
STAGE 05 // FRAMING 256B Payload Chunks

Packetization (Payload Splits into Packets)

Splits binary payload into 256-byte chunks with 16-byte sequence header (`ITAN` magic, packet ID, count).

PKT #001 (256B) PKT #002 (256B) PKT #003 (256B)
6
STAGE 06 // INTEGRITY uint32 Checksum

CRC32 Verification Occurs

Computes 32-bit zlib checksum per chunk to enable packet-by-packet error detection at receiver.

Polynomial Calculation: zlib.crc32(chunk) 0x94B2C81F ✓ PASS
7
STAGE 07 // TRANSMISSION Acoustic / Loopback

Transmission Waveform

Packets enter transmission link channel via verified software loopback or acoustic FSK sound tones.

8
STAGE 08 // RECEIVER Ingestion Node

Receiver Ingests Packets

Receiver ingests incoming packet frame stream, validates 16-byte magic headers, and parses packet IDs.

RX Ingest Buffer: 4 Frames Magic `ITAN` Verified ✓
9
STAGE 09 // REASSEMBLY Sequence Reordering

Packets Reassemble

Reorders packet stream by sequence number, discards corrupted chunks, and deserializes VQ tensors.

[001] →[002] →[003] →[004] →[005] Complete
10
STAGE 10 // SYNTHESIS Neural Decoder

Waveform Reconstructs

EnCodec neural decoder synthesizes discrete VQ code tensors back into 24kHz audio waveform signal.

✓
FINAL STAGE // OUTPUT 24kHz Audio Restored

Reconstructed Voice Speech

24kHz Intelligible Speech Restored for playback.

06 / Technical Knowledge Base

Frequently Asked Questions

iTantra is a low-bandwidth multilingual voice communication system. It compresses voice audio using Meta EnCodec neural speech tokens and transmits 256-byte packet streams over bandwidth-constrained links.
EnCodec uses Vector Quantization (VQ) neural codebooks to compress 24kHz voice audio down to 6.0 kbps (and lower), achieving significant data reduction while preserving speech intelligibility.
ggwave is a lightweight acoustic data-over-sound protocol that encodes binary packets into sound tones for transmission across audio links or software loopback.
Packetization breaks continuous VQ byte streams into 256-byte sequence-numbered frames so that individual lost or corrupted packets can be isolated independently.
CRC32 (Cyclic Redundancy Check) computes a 32-bit checksum for each packet payload before transmission, enabling error detection at the receiver.
iTantra's primary function is neural voice-to-voice communication. However, it integrates AI4Bharat IndicConformer-600M for optional speech-to-text transcription.
Support includes Hindi, Gujarati, Marathi, Kannada, Malayalam, Tamil, Telugu, Odia, Bengali, and English.
By transmitting compact VQ neural codebook indices rather than uncompressed PCM audio, payload size is reduced significantly, allowing voice communication over constrained links.
The receiver depacketizes and verifies CRC32 checksums, reassembles VQ code tensors, and passes them to the EnCodec neural decoder to synthesize 24kHz voice output.
Software loopback is verified PASS. Physical acoustic transmission requires compatible speaker and microphone acoustic hardware conditions.
