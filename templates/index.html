Continuous Signal Transmission System

Scroll to trace speech transformation from raw PCM audio through neural codebooks and packet frames to 24kHz output speech.

1
STAGE 01 // INPUT

Voice Audio Input

Raw microphone capture (24kHz PCM signal data).

2
STAGE 02 // NEURAL QUANTIZATION

Meta EnCodec Encoder

Quantizes 24kHz speech into discrete Vector Quantization (VQ) codebook indices at target 6.0 kbps bandwidth.

3
STAGE 03 // REPRESENTATION

Compressed Code Tensors

Compact VQ index matrices representing acoustic features with up to 18x–235x data reduction.

4
STAGE 04 // SERIALIZATION

Binary Byte Buffer

Encodes codebook tensors and scale metadata into a compact binary byte payload stream.

5
STAGE 05 // FRAMING

Packetization

Splits binary payload into 256-byte chunks, prepending a 16-byte header (`ITAN` magic, packet ID, total count, CRC32, chunk length).

6
STAGE 06 // INTEGRITY

CRC32 Checksum Verification

Calculates 32-bit checksum per chunk to enable packet-by-packet error detection at the receiver.

7
STAGE 07 // TRANSMISSION

ggwave Protocol Link

Transmits framed binary payload via verified software loopback channel or acoustic audio tones.

8
STAGE 08 // RECEIVER

Receiver Ingestion Node

Ingests packet frames, parses 16-byte headers, and validates CRC32 checksum integrity.

9
STAGE 09 // REASSEMBLY

Sequence Reassembly

Reorders sequence-numbered packets, discards corrupted chunks, and deserializes VQ code tensors.

10
STAGE 10 // SYNTHESIS

EnCodec Decoder

Synthesizes discrete VQ code tensors back into 24kHz audio waveform signal.

✓
FINAL STAGE // OUTPUT

Reconstructed Voice Speech

24kHz Intelligible Speech Restored for playback.

05 / Technical Knowledge Base

Frequently Asked Questions

iTantra is a low-bandwidth multilingual voice communication system. It compresses voice audio using Meta EnCodec neural speech tokens and transmits 256-byte packet streams over bandwidth-constrained links.
EnCodec uses Vector Quantization (VQ) neural codebooks to compress 24kHz voice audio down to 6.0 kbps (and lower), achieving significant data reduction while preserving speech intelligibility.
ggwave is a lightweight acoustic data-over-sound protocol that encodes binary packets into sound tones for transmission across audio links or software loopback.
Packetization breaks continuous VQ byte streams into 256-byte sequence-numbered frames so that individual lost or corrupted packets can be isolated independently.
CRC32 (Cyclic Redundancy Check) computes a 32-bit checksum for each packet payload before transmission, enabling error detection at the receiver.
iTantra's primary function is neural voice-to-voice communication. However, it integrates AI4Bharat IndicConformer-600M for optional speech-to-text transcription.
Support includes Hindi, Gujarati, Marathi, Kannada, Malayalam, Tamil, Telugu, Odia, Bengali, and English.
By transmitting compact VQ neural codebook indices rather than uncompressed PCM audio, payload size is reduced significantly, allowing voice communication over constrained links.
The receiver depacketizes and verifies CRC32 checksums, reassembles VQ code tensors, and passes them to the EnCodec neural decoder to synthesize 24kHz voice output.
Software loopback is verified PASS. Physical acoustic transmission requires compatible speaker and microphone acoustic hardware conditions.
