Knowledge Base

Frequently Asked Questions

iTantra is a low-bandwidth multilingual voice communication system. It compresses voice audio using Meta EnCodec neural speech tokens and transmits data packets over bandwidth-constrained links.
EnCodec uses Vector Quantization (VQ) neural codebooks to compress 24kHz voice audio down to 6.0 kbps (and lower), achieving over 200x to 900x data compression while preserving speech intelligibility.
ggwave is a lightweight acoustic data-over-sound protocol that encodes binary packets into sound tones for transmission across audio channels.
Packetization breaks continuous VQ byte streams into indexed chunk frames (256 bytes) so that individual lost or corrupted packets can be isolated and verified independently.
CRC32 (Cyclic Redundancy Check) computes a 32-bit checksum for each packet payload before transmission, enabling 100% data corruption detection at the receiver.
iTantra's primary function is voice-to-voice neural communication. However, it includes AI4Bharat IndicConformer-600M for optional speech-to-text transcription.
Support includes Hindi, Gujarati, Marathi, Kannada, Malayalam, Tamil, Telugu, Odia, Bengali, and English.
By transmitting compact VQ neural codebook indices rather than raw PCM audio, payload size is reduced by up to 940x, allowing voice communication over constrained connections.
Audio processing follows the current local system configuration. Uploads and generated WAV files are processed locally on the system.
Software loopback is verified PASS. Physical acoustic mode requires compatible speaker and microphone acoustic hardware conditions.
